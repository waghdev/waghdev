# Hi, I'm Devendra

I build AI systems that do real work in production, not demos.

I'm building **[Scaile AI](https://scaileai.com)**, a fully managed AI call center. We design, build, run and keep improving AI voice agents that answer real phone lines for businesses in the US, plus the workflow automation around them.

### What I've built

- An AI intake call center for a nationwide legal network that answers 100% of its inbound calls, in English and Spanish, with deterministic decision logic and compliance built in
- Inbound and outbound AI voice agents for home-service businesses and lead-generation agencies
- The production layer behind them: webhook middleware, CRM integrations, staging and production environments, simulation and regression testing, dashboards and alerting

Client work lives in private repositories. Public reference projects are on the way.

### How I build

- The LLM runs the conversation; plain code makes the decisions
- Every bug found in a live call becomes a regression test
- Nothing reaches production without going through staging first

Before Scaile AI, I spent two years at Accenture building Java and Spring Boot microservices for FedEx.
